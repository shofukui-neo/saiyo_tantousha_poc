# 高卒（新卒）採用企業リストアップシステム

高校新卒を採用している企業を、検索APIで発掘し、各社の**自社採用ページ上の高卒新卒シグナル**で判定して、単一CSVに出力する。

## 定義（このシステムがリスト化する対象）
「**高校新卒を採る企業**」＝ 高卒シグナル（高卒／高等学校卒業見込 等）**かつ** 新卒シグナル（新卒／新規学卒／◯年3月卒 等）**かつ** 現役の募集シグナル（募集要項／初任給／エントリー／該当年度 等）を、企業の自社ページ上で満たすもの。中途「高卒以上」求人・派遣・アルバイト専業・解説記事/ランキングは除外する。

## なぜこの方式なのか（重要な前提）
高卒採用は制度上、求人が**高校とハローワーク経由で非公開に流通**するため、「今まさに高卒新卒を募集中の企業名」を無認証・robots遵守で一覧化できる公開媒体が事実上存在しない（求人ボックスは一覧に社名が出ない／ハローワークは高卒新卒を一般非公開／ジョブドラフトNavi・高卒Webはログインゲート）。
そこで発掘の向きを変え、**検索APIで高卒採用の募集ページを発掘 → 企業の自社ページで判定 → 企業名を抽出**する。robots遵守（自社ページのみ取得）で、企業名・法人番号まで確実に取れる。

### カバレッジの限界（正直な明記）
本方式で取れるのは「**高卒新卒採用を自社サイト等で公開している企業**」の部分集合。学校斡旋のみ・ハローワークのみで募集する中小は公開情報に出ず、取りこぼす。網羅性を上げたい場合はジョブドラフト提携データ／ハローワーク求人票等の取込（別途）を併用する。

## セットアップ
`.env` に検索APIキーを**いずれか1つ**設定する（未設定なら実行時に案内が出る）。

| プロバイダ | 環境変数 | 無料枠 | 取得先 |
|---|---|---|---|
| Google Programmable Search（推奨） | `GOOGLE_CSE_KEY` + `GOOGLE_CSE_CX` | 100件/日 | programmablesearchengine.google.com（cx）＋ console.cloud.google.com（APIキー・Custom Search API有効化） |
| Brave Search API | `BRAVE_API_KEY` | 2000件/月 | api-dashboard.search.brave.com |
| Serper.dev | `SERPER_KEY` | 従量（少額） | serper.dev |

gBiz補完（業種/所在地/従業員/法人番号/代表者）は既存 `GBIZ_TOKEN` があれば自動で有効。

## 実行
```bash
npm run koso                                   # 既定クエリで発掘（target 200）
npm run koso -- --target 300 --pages 3         # 目標社数・1クエリあたり取得ページ数
npm run koso -- --prefectures 東京都,大阪府 --industries 製造,建設,運輸
npm run koso -- --queries "高卒採用 募集要項 初任給;高卒 新卒 電気工事 募集"  # クエリ直接指定
npm run koso -- --no-gbiz                       # gBiz補完なし
npm run koso:test                              # 判定ロジックの自己テスト（ネット不要）
```

### 主なオプション
- `--out <path>`：出力先（既定 `data/leads-koso-shinsotsu.csv`）
- `--target <n>`：目標社数（既定200）／`--pages <n>`：1クエリの取得ページ数（既定2＝最大20件）
- `--prefectures` / `--industries`：クエリ行列を都道府県×業種で拡張
- `--max-companies <n>`：取得（fetch）するページ数の上限（コスト制御）
- `--year <yyyy>`：現役判定の基準年（既定2026）／`--delay <ms>`：クエリ間隔

## 出力CSV（列）
`企業名, 法人番号, 高卒区分, 根拠キーワード, シグナルスコア, 業種, 所在地, 従業員数, 代表者名, 公式URL, 電話番号, 根拠URL, 取得元媒体, 検索クエリ, 社名抽出元, 取得日`

- **根拠キーワード / 根拠URL**：なぜ高卒新卒と判定したかの証跡（合致した高卒・新卒・募集キーワードと、そのページ）。
- **高卒区分**：`高卒新卒`（本システムの対象定義）。

## 構成
| ファイル | 役割 |
|---|---|
| `src/koso-search.js` | 検索APIのプラガブル層（Google CSE / Brave / Serper を自動選択、共通形で返す） |
| `src/koso-signal.js` | 高卒新卒シグナル判定＋企業名抽出（純ロジック・テスト可） |
| `src/build-koso-list.js` | オーケストレータ（発掘→媒体除外→取得→判定→社名抽出→gBiz補完→名寄せ重複排除→CSV） |
| `test/koso-signal.test.js` | 判定・社名抽出の自己テスト |

流用している既存資産：`polite.js`（robots遵守取得）, `fetch.js`(extractText), `structured.js`(JSON-LD), `search.js`(媒体ドメイン除外), `gbiz.js`(属性補完), `csv.js`(名寄せ・CSV)。

## 動作検証（実装時）
- 判定/社名抽出の自己テスト 9件 PASS。
- 実ページ検証：荏原製作所（高卒採用ページ）・大倉工業（新卒募集要項）を判定true→社名抽出→gBizで法人番号・所在地補完まで実走確認。
- オーケストレータ全体：検索結果に混ぜた媒体URL（求人ボックス）・ランキング記事を除外し、企業2社のみをCSV化することを確認。
