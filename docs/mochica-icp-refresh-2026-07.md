# MOCHICA 既存顧客プロファイル分析 ＆ ICP再定義（2026-07）

## 0. サマリ（3行）
- MOCHICA既存顧客429社＋Salesforce全リード86,610件を突合し、**属性別の実コンバージョン率**でICPを再定義した。
- 旧仮説「従業員50〜150名の中小」は**誤り**。データが示す本命は **従業員100〜2,000名（スイート300〜500名）／年間新卒6名以上／非IT業種（流通・小売・金融・介護・メーカー機電・商社）**。
- この実証ICPで未コンバートのリードをスコアし、**類似・高ポテンシャル企業8,126社**をランク化。上位200社を `data/mochica-lookalike-top200.csv` に出力した。

## 2. 既存顧客の傾向・詳細属性（実データ）

### 2-1. 契約プラン ― 8割が最下位プラン
| プラン | 比率 |
|--|--|
| ミニマムプラン | **76.3%** |
| スタンダード | 12.8% |
| ミドル/データ利用 | 10.9% |
- アップグレード実績はわずか8/430。→ **単価は低いが数で取る顧客層**。ランドは最小プランが定石、拡大はアップセル設計が課題。

### 2-2. 従業員規模 ― “中小”ではなく“中堅”
既存顧客（突合済）と全コンバートで一致した傾向。**100〜300名が最多、300〜500名が最も成約しやすい**。

| 従業員バンド | 成約率 | 対全体リフト |
|--|--|--|
| 300〜500名 | **23.9%** | **1.41x（ピーク）** |
| 500〜1,000名 | 22.1% | 1.30x |
| 1,000〜2,000名 | 22.2% | 1.30x |
| 100〜300名 | 19.1% | 1.12x |
| 50〜100名 | 13.5% | 0.79x |
| 30〜50名 | 10.1% | 0.59x |
| 1万名超 | 7.9% | 0.47x |

→ **旧ICPの「50〜150名」は成約率14%未満のゾーンで、実際のスイート（300〜500名）を外していた。**

### 2-3. 新卒採用規模 ― 「年6名」が分岐点
| 年間採用人数 | 成約率 | リフト |
|--|--|--|
| 6〜10名 | **26.3%** | **1.55x（最良）** |
| 21〜30名 | 26.0% | 1.53x |
| 11〜20名 | 25.9% | 1.52x |
| 31〜50名 | 23.9% | 1.41x |
| 3〜5名 | 13.2% | 0.78x |
| 1〜2名 | 3.6% | 0.21x（不毛） |

→ **年6名以上の新卒採用で成約率が急伸。**「大量エントリー×選考管理の痛み」が顕在化する規模。1〜2名は狙わない。

### 2-4. 業種 ― “非IT・現場人材大量採用”に刺さる
上位（母数≥40、全体成約率17%）：

| 業種 | 成約率 | リフト |
|--|--|--|
| 流通・小売・物販 | **39.9%** | 2.35x |
| 金融・保険（信金・地銀含む） | 35.3% | 2.07x |
| 介護・保育・医療法人 | 31.0% | 1.82x |
| メーカー（機械・電気・電子） | 29.7% | 1.75x |
| 公共インフラ・エネルギー・環境 | 26.9% | 1.58x |
| 商社 | 25.7% | 1.51x |
| その他サービス（個人向け）／ドラッグストア／地銀 | 24〜25% | 1.4x台 |
| メーカー（素材・食品・医薬品）／不動産・建設・設備／運輸・物流 | 23〜24% | 1.4x |

下位（避けるべき、成約率<7%）：
- **ソフトウェア6.2% / ソフトウェア業0.9% / インターネット関連2.0% / 情報処理7.1%**（＝自前ツール文化で刺さらない）
- 建設（単体）7.7% / 建設・設備3.7% / 建築設計4.0% / 化学7.9% / 機械6.4% / 金属製品5.5% / 住宅6.0% / 広告5.0% / 印刷4.8%

> **戦略的含意:** 現行の候補生成パイプラインは GitHub/connpass/Wantedly など**技術系ソース中心**だが、実データ上ITは最も成約しない。母集団を **流通・小売／金融／介護・医療／メーカー機電／商社／物流** の非IT・地場中堅へ寄せるべき。

## 3. 更新したICP（コード反映済み）

| 軸 | 旧定義 | 新定義（実データ） | 反映先 |
|--|--|--|--|
| 従業員規模 | スイート50〜150名 | **有効100〜2,000名／スイート300〜500名** | `config.js` ICP_EMP_*、`mochica-fit.js` `scoreSize` |
| 新卒採用人数 | 大型枠=10名以上 | **6名以上で高成約**（1〜2名は不毛） | `mochica-fit.js` `FUNNEL_TH.hire`=6, `scoreFunnel` |
| 業種 | （軸なし） | **業種フィット±12補正を新設**（勝ち業種+/IT・建設単体−） | `mochica-fit.js` `scoreIndustry`（新規） |

- `scoreSize` を成約率カーブに沿って全面改訂（300-500=100点をピークに、<50名と1万名超を減点）。
- `scoreIndustry` を新設し、実成約率テーブル `INDUSTRY_LIFT` で加減点。業種列が空なら中立(0)。
- セルフテストは新ICPの期待値に更新済み（`SELFTEST PASSED`）。

**動作例（`scoreMochica`）:**
- 理想像（流通/400名/新卒11-15名/電話+担当者+マイナビ掲載）→ **100点・今週架電**
- 負け筋（ソフトウェア/30名/新卒1-2名）→ **27点・後回し**

## 4. 類似・高ポテンシャル企業リスト

### 手法
未コンバートのSFリードのうち **業種＋従業員数＋採用人数＋電話が揃う** 企業を母集団とし、各社の
`成約見込み ≈ 全体成約率 × リフト(業種) × リフト(規模) × リフト(採用人数)`（素朴ベイズ）で類似スコア化。
**既存顧客（勝ち済み）・NG（アプローチ禁止7,369社）・アーカイブ（死に筋）は除外**。社名で名寄せ重複排除。
生成: `scripts/build-lookalike-list.js`。

### 結果
- スコア対象 **8,126社**（ユニーク社名）。スコア≥40が411社、≥30が714社。
- 出力: 全件 `data/mochica-lookalike-scored.csv` / 上位 `data/mochica-lookalike-top200.csv`
- TOP200構成: 業種は商社43・メーカー機電36・金融32・流通小売26・介護25…、規模は300-500名78社／100-300名53社／500-1000名44社。状況はリサイクル・未接触・新規が中心（＝再アプローチ余地あり）。

## 5. 注意・次アクション
- **スコアの解釈:** `成約見込み%` は独立性を仮定した相対指標（絶対値は上振れしやすい）。ランク付けの根拠として使い、`業種lift/規模lift/採用lift` の内訳で妥当性を確認できる。
- **母集団の性質:** 上位はSF既存リードの「リサイクル/未接触」が中心＝**過去に接点はあるが未成約**。再アプローチ優先度の再設定に直結する。まったくの新規開拓には、この実証ICP（非IT×300-500名×新卒6名+）で候補生成ソースを差し替える必要がある。
- **粒度のゆれ:** 業種の`商社`は高成約(26%)だが`商社(鉄鋼・金属)`等の細分ラベルは低い。テーブルは主要ラベルを実測値で、表記ゆれはキーワード概算で処理している。
- **推奨次アクション:**
  1. TOP200を営業リストへ投入し、リサイクル/未接触セグメントの再架電を実施。
  2. 候補生成（harvest系）のソースをIT系から流通・金融・介護・メーカー機電へ転換。
  3. アップセル余地（8割がミニマム）に対し、規模300-500名×新卒二桁採用の顧客へミドル/スタンダード提案を設計。
