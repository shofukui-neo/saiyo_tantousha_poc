# 完全新規 × ICP完全適合 ライブ発掘 — ランブック

ユーザー指定（2026-07）:「今あるものではなく**完全新規**（既存の自社マスタ・CRMに無い）で、ICP完全適合・**採用担当者名を優先**（採用担当者名 ＞ 代表者名 ＞ 名前なし）のリストを最大数」。既存マスタからの抽出（[icp-perfect-named-1000-runbook.md](icp-perfect-named-1000-runbook.md)）ではなく、マイナビをライブ探索して**ゼロから発掘**する。

## 成果物 / コマンド
- **`data/leads-icp-fresh-10000.csv`** — 連絡先区分でランク（採用担当者名→代表者名→名前なし、各内アポ期待度降順）
- 発掘: `npm run icp:fresh`（= `node src/build-icp-fresh-1000.js`、env駆動・再開可・バックグラウンド長時間）
  - `ICP_FRESH_KEYWORDS`（キーワードファイル）/ `ICP_FRESH_OUT` / `ICP_FRESH_TARGET` / `ICP_FRESH_MAX` / `MYNAVI_GRAD_YEAR`（28既定）
- 代表者名補完: `npm run icp:fresh:rep`（= `node src/enrich-fresh-rep.js`、gBiz 2段・GBIZ_TOKEN必須）

## 【重要】マイナビ社名の注記による「偽の完全新規」バグ
- マイナビ表示名は末尾 **NEW** バッジや **【親会社/グループ】(株)（…グループ）** 注記を含む。これを剥がさず正規化すると除外索引に当たらず、**実は既出の社が「完全新規」に混入**（実測 1,026社中 **539=46%**）。
- 修正: `stripAnn`（注記除去）＋ `mkey = normCompanyName(stripAnn(name))` で**除外索引・候補・出力・gBiz突合の全てを統一キーで突合**。表示名は `cleanDisplay` で整形。
- **教訓: マイナビ由来の社名は必ず `stripAnn` してから正規化・突合すること。**

## gBiz代表者名の補完（2段）
- 代表者名は gBiz **検索list には無く、詳細エンドポイント（`gbizGet(法人番号)`）のみ**返す。→ `gbizSearch(name)` → 一致社の `corporateNumber` → `gbizGet` の2段が必須。突合は `mkey`。法人番号も併せて充填。
- 実測充填率 **約17%**（net-new SMEは登記の代表者名欠落・社名ミスマッチが多い）。さらに伸ばすには公式URL発見→web-crawl代表者名（70-88%、別層）。

## 母集団の壁（実測・正直な上限）
- マイナビ掲載企業の**約89%が既に除外索引（特にSF全リード86,674）に存在**＝完全新規は薄い。
- キーワード多様化が唯一のcountレバー（フリーワード検索は1KW=100社上限・ページ送り無効）。掃引の推移（28卒→+27卒→+市→+具体業種→+職種/ニッチ）:
  - 486 → 531 → 683 → 729 → 757（+45, +152, +46, +28 と**逓減**）
- 理論上限（net-new約11% × 規模適合約30% ≒ 700〜1,300）に一致。**10,000は母集団上、到達不能**。
- 使用キーワード資産: `data/icp-fresh-keywords{,-city,-terms,-jobs}.txt`（計約15,600 keyword-fetch）。

## 最終成果（2026-07-29）
- 完全新規 ICP完全適合 = **757社**（**採用担当者名 37 ／ 代表者名 117（gBiz補完）／ 名前なし 603**）。
- 全社検証済: 従業員100-2000名(100%)・電話妥当(100%)・新卒媒体掲載・非IT・既存10万社に不在（`mkey`突合）・社名重複0。
- 品質パス: マイナビ面見出し/業務語（人材/業界研究/専門/人材開発 等）を氏名から除外（evaluateに `BAD_NAME` ガード追加）。社名の残存ブラケット除去。
- ※10,000は不可。追加のcountはコード改善でなく**別ソースのリソース判断**（他媒体の氏名非公開＝tier下がる／公式URL発見→web-crawl／規模帯の緩和）に依存。
- 到達実数の推移（各キーワード軸の寄与）: 486(28卒) → 531(+27卒) → 683(+市) → 729(+具体業種語) → **757**(+職種/ニッチ)。逓減で飽和。
