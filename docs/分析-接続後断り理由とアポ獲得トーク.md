# 採用担当者 接続後の「断わり理由」と「アポ獲得トーク」傾向分析

対象データ: BALESCLOUD 既存リスト（22,892件・266列, 2026-07-06時点） / Salesforce MOCHICA参照（86,674件）
再現スクリプト: `src/analyze-talk-rejection.js` → `node src/analyze-talk-rejection.js`
出力CSV: `data/analysis-断り理由.csv` / `data/analysis-アポ獲得トーク.csv` / `data/analysis-talk-lift.csv`

## 0. 前提：分析はBALES架電履歴に依拠

- **SFリスト（Salesforceレポート）は「リード状況」1列しか持たず、架電コメント・断り理由・トーク列が一切ない。** そのため断り理由・トーク分析は**BALES側の架電履歴が唯一の情報源**。SFはリード状況ファネル（新規41.3%／アーカイブ18.8%／コンバート17.0%…）の参考に留める。
- 「採用担当者 接続後」の定義 = `コール結果1：結果` が **「担当者接触：…」で始まる架電**（担当者不在・受付ブロック・鳴りっぱなしは"接続前"として分母から除外）。

## 2. ① 断わり理由分析（お断り 6,663件）

構造化フィールド「ペンディング理由」を優先し、未入力（約6割）はコメント自由記述で補完した統合分類。

| 断り理由 | 件数 | 比率 | 代表コメント |
|---|---:|---:|---|
| **検討時期が先・タイミング** | 1,847 | 27.7% | 「今のところ検討時期じゃない」「決まった」 |
| その他（複合・分類外の自由記述） | 1,904 | 28.6% | 状況説明混じりの複合ノート |
| **ニーズ・課題感なし** | 1,088 | 16.3% | 「必要ないとのこと」「困っていない」 |
| **既存ツール・他社ATS/媒体で充足** | 830 | 12.5% | 「マイナビとかんり君でまかなえている」 |
| （コメントなし） | 281 | 4.2% | — |
| 予算なし | 166 | 2.5% | 「予算も決まっていて捻出が難しい」 |
| **新規営業を一律お断り** | 147 | 2.2% | 「新規お断り」「決まったところしかやりとりしない」 |
| 新卒採用していない・担当外 | 144 | 2.2% | 「新卒はやっていない／中途メイン」 |
| 採用規模が小さい・縮小 | 90 | 1.4% | 「採用人数が少なく不便がない」 |
| LINE方針・セキュリティNG | 89 | 1.3% | 「LINEは会社的にNG」 |
| 決裁権限なし・権限外 | 25 | 0.4% | 「上に確認しないと」 |
| 即切り・一方的遮断 | 24 | 0.4% | 「話できないタイプ」 |
| アプローチ禁止・架電拒否 | 21 | 0.3% | 「今後かけないで」 |

### 読み解き
- **断りの約7割は「タイミング」「ニーズ/課題感なし」「既存充足」の3つ**。＝製品否定ではなく、**"今じゃない・困っていない・足りている"** という現状肯定バイアス。→ 課題を"気づかせる"トークが刺され余地。
- **「新規営業を一律お断り／即切り／アプローチ禁止」＝製品以前の門前払いは合計 約3%** と少数。断りの大半は会話が成立した上での"現状肯定"型。
- **LINE方針NGは1.3%と小さい**。「LINE連携＝セキュリティ懸念で無理」という先入観は思ったほど障壁になっていない。

### ⚠️ 解釈上の注意
- **「検討時期が3カ月以上先」はBALESの"ソフトNo"デフォルトタグとして多用**されている（例: 実コメントが「すぐ切られた」でもこのタグが付く）。純粋なタイミング反論と一般的な軽い断りが混在している点に留意。
- 「その他」28.6%は状況説明が混じる複合ノートで、単一理由に割り切れないもの。

## 3. ② アポ獲得トーク傾向分析（アポ獲得 830件）

アポ獲得コメントは定型ヒアリングテンプレ（■基本情報／商談日程／■採用状況：目標人数・内定承諾・母集団形成方法・年間接触人数）に沿って記録される。そこに現れるトーク要素の出現率:

| トーク要素 | 出現率 | 中身 |
|---|---:|---|
| **母集団形成の文脈** | 92.8% | ナビ・説明会・エントリー数など集客の話 |
| **採用計画・目標人数の具体化** | 88.8% | 目標人数／内定承諾数を握る |
| **つなぎ止め・歩留まり改善** | 55.1% | 歩留・辞退防止・内定者フォロー・温度感維持 |
| **LINE連携ATSの提案（コア訴求）** | 50.7% | LINEで学生と繋がる採用管理 |
| 料金・費用対効果の訴求 | 33.6% | MOCHICA費用感の提示 |
| 他社導入事例・実績の提示 | 19.5% | 同業・同規模の事例 |
| 学生コミュニケーション/連絡改善 | 15.7% | 連絡がつく・返信率 |
| 選考・面接管理の効率化 | 4.8% | 日程調整・工数削減 |

### 属性別アポ獲得率（分母＝その属性で接続できた件数）
- **利用中ATS別**: sonarATS **26.7%**（23/86）、NEXT **25.0%**（11/44）、i-web 13.2%、キャリタスContact 12.5%、採用一括かんりくん 11.9% ＞ ATS「無し」9.9%。
  → **既にATSを使っている企業のほうがアポ率が高い**。"採用管理の必要性を既に理解している層＝乗り換え・併用提案が刺さる"。ホワイトスペース（ATS無し）より既存ATS層が狙い目。
- **従業員規模別**: 300名 **19.7%**、100名 11.7% ＞ 500名7.8%／1000名6.1%。→ **中堅（100〜300名）が最も獲得しやすい**。
- **業種別**: 機械設計28.6%、プラント・エンジニアリング20%、幼稚園・保育園/教育19%、共済15.4%、医療機関15.8%、福祉・介護13.3% など、**非IT・現場採用系**で高い。

## 4. ③ トークlift分析（アポ獲得 vs お断り の語彙差）

同じ語が「アポ獲得コメント」と「お断りコメント」でどれだけ出現率が違うか（lift = アポ出現率 ÷ お断り出現率, >1でアポに効く語）。

| lift上位（アポに効く語） | lift | アポ% | お断% |
|---|---:|---:|---:|
| 接点 | 18.5 | 3.6 | 0.2 |
| 事例 | 14.8 | 12.4 | 0.8 |
| 料金 | 12.6 | 1.3 | 0.1 |
| 見直し | 11.6 | 13.3 | 1.1 |
| 承諾 | 10.5 | 77.3 | 7.4 |
| 面接 | 9.5 | 6.9 | 0.7 |
| 工数 | 9.1 | 20.1 | 2.2 |
| エントリー | 8.4 | 30.7 | 3.6 |
| 選考 | 7.8 | 31.8 | 4.1 |
| フォロー | 7.8 | 10.1 | 1.3 |
| 説明会 | 7.7 | 52.5 | 6.8 |
| 辞退 | 7.7 | 21.8 | 2.8 |
| 母集団 | 7.3 | 88.8 | 12.2 |
| 予算 | 7.1 | 36.0 | 5.0 |
| 費用 | 7.0 | 27.2 | 3.9 |
| 内定者 | 6.8 | 12.4 | 1.8 |
| 歩留 | 5.0 | 33.3 | 6.7 |

> **アポは"採用実務の具体語彙（選考・面接・エントリー・歩留・内定者・承諾・辞退・工数）に踏み込み、費用・事例で握れた"時に取れている。** 逆にお断り会話はこれらの語がほぼ出ない＝**具体の採用オペレーション課題に入る前に切れている**。

### ⚠️ 解釈上の注意
lift値の絶対値は、アポ獲得コメントが長い定型テンプレのため全体的に高く出やすい（テキスト量バイアス）。**大小の順位（どの語が相対的にアポに効くか）を読む指標**として扱う。

## 5. 示唆・アクション

1. **接続後トークの初速で"具体課題"に入れるか勝負**。断りの7割は「今じゃない/困ってない/足りている」型＝現状肯定。冒頭で **母集団→歩留まり→内定者フォロー** の順に採用オペレーションの具体を投げ、"エントリー数・辞退率・選考工数"の言葉を引き出せた会話がアポ化している。
2. **ターゲティングは「既存ATS利用×中堅100〜300名×非IT現場採用系」に寄せる**。ATS無しのホワイトスペースよりアポ率が高い（sonarATS/NEXT利用企業で25%超）。乗り換え・併用の提案が刺さる。
3. **"検討時期が先"の27.7%は再架電資産**。ソフトNoタグの混在はあるが、`カスタム情報：検討開始時期`（構造化922件）と突合すれば具体月の再アプローチリストになる（既存の `src/extract-kento-jiki.js` 出力を活用）。
4. **料金・事例カードの早期提示**。lift上位の「料金」「事例」「費用」はアポ会話に特徴的。金額の透明提示＋同業同規模事例をトークの武器に。
5. **LINE-NG懸念は過大評価**（断りの1.3%）。セキュリティNGを恐れて訴求を弱める必要はない。

## 7. 頻発お断りシーン × 克服プレイブック（生コメントから）

お断りコメント6,202件（コメント有）に対する特定シーンの出現件数と、アポ獲得コメントの「何に興味を持ってアポをくれたか」欄から逆算した克服アングル。

### シーン① 「必要ない／間に合ってる」＝現状肯定（690件・11.1%）＋「困ってない／課題感ない」（386件・6.2%）
- 実際の断り: 「特に必要ない」「間に合ってます」「困っていない」「課題感は正直ない、今特に考えていない」
- **克服すべき核心**: 製品否定ではなく**"歩留まり・工数を課題として認識していない"**。特に「歩留りの課題感はマイナビのみで考えている」＝母集団（入口）しか課題と思っておらず、内定承諾・辞退（出口）が盲点。
- **克服トーク**: 冒頭を提案でなく**診断質問**に。「目標◯名に対し、今の内定承諾は何名ですか？」「説明会に来た学生、選考中に何割離脱していますか？」→ 目標と承諾の差＝歩留ロスを本人に気づかせる。アポ獲得側は「内定承諾率を上げたい／つなぎ止め」が最頻の興味理由。

### シーン② 「公式LINE使ってるから足りてる」（445件・7.2%）★最重要
- 実際の断り: 「LINE使い始めていた、今困ってることない」「公式LINEは使っている、そのくらいで十分」「マイナビで事足りているので新しいのは考えてない」
- **克服すべき核心**: **公式LINE（一斉配信）とMOCHICA（LINE連携の選考管理・歩留・個別対応）を混同**している。「LINEがある＝足りてる」の誤解。営業メモにも「モチカをわかってないので歩留メインで話した方がいい」と明記。
- **克服トーク**: アポ獲得の興味理由に「**ビジネスLINEとMOCHICAの違い**」「公式LINEの違いの話と値段説明でアポ」が実在。→「公式LINEは"配信"、MOCHICAは"一人ひとりの選考進捗と歩留まり管理"で役割が違います」と差分を明確化。**LINE非利用/方針NGの相手にはLINEを引っ込め、歩留・母集団を主語に切替**（アポ側の課題ワードは母集団84.9%＞LINE活用45.1%＞歩留25.7%）。

### シーン③ 「ネオキャリア既取引／他部署から連絡済み」＝社内バッティング（261件・4.2%）
- 実際の断り: 「ネオキャリアの取引ある部署以外はつながない」「ネオキャリアから山ほど電話が来る、もうやめてほしい」「別窓口のネオから連絡あって断った…連結してほしい」「ネオキャリアブロック」
- **克服すべき核心**: **これはトークで克服する問題ではなく、架電前の名寄せ・抑止の運用課題**。複数部署が同一企業に重複架電し心証を毀損している。
- **克服アクション**: 架電前に**既存取引・他部署接触の名寄せ**（リポジトリの `アプローチ禁止企業一覧.txt` / `src/suppression.js` を適用）。接触済み企業は「別部署から」ではなく**社内で担当を連結**してから当てる。リスト衛生の改善で防げる損失。

### シーン④ 「新規営業は一律お断り／即切り」＝到達前遮断（新規お断り212件・3.4%＋即切り74件・1.2%）
- 実際の断り: 「新規お断り」「決まったところしかやりとりしていない」「すぐ切られた」「冒頭から必要ない」
- **克服すべき核心**: 用件を聞く前の反射的遮断。商材ではなく**開口一番の入り方**の問題。
- **克服トーク**: 「営業」と名乗らず**"採用の情報提供／他社事例の共有"**の入りに変える（アポ側は「他社がLINEでどんな施策しているか見てみて！」「市況・学生の動向データ」への関心でアポ化）。15秒以内に"御社の同業がやっている具体施策"を提示できるかが分岐。

### シーン⑤ 「繁忙／落ち着いてから／もう決まった」＝タイミング（繁忙152件・2.5%＋採用終了94件・1.5%）
- 実際の断り: 「今は繁忙で忙しい」「採用が落ち着いてから」「26卒は決まった」
- **克服すべき核心**: 今期は終わっていても**次年度の入口（IS・つなぎ止め）は今が仕込み時**という時間軸のズレ。
- **克服トーク**: 「今期でなく**次卒のIS後つなぎ止め**の話」に振る（アポ側の最頻興味＝「ISで出会った学生の繋止め・温度感の保ち方」）。＋ `カスタム情報：検討開始時期`（構造化922件）で具体月を持つ相手はその月の1〜2ヶ月前に再架電予約。

### シーン⑥ 「担当が退職／異動した」＝引き継ぎ断絶（116件・1.9%）
- 実際の断り: 「朱雀さん退職」「前の担当者から聞いていない／引き継いでいない」
- **克服すべき核心**: 過去の接点・提案履歴が新担当に伝わっておらずゼロリセット。
- **克服トーク**: 「モチカは引き継いでなく、LINEの使い方に興味を持った」でアポ化した例あり。→**過去接触を負債でなく資産**として「以前◯◯のお話をしていた件で」と接続し、新担当にゼロベース提案。

### シーン⑦ 「新卒やってない／中途のみ」＝ICP外（79件・1.3%）
- 実際の断り: 「新卒はやっていない／中途メイン」「来年度から大卒取らない方針」
- **克服すべき核心**: トークでなく**リスト精度**の問題。新卒非該当は克服対象でなく除外対象。
- **克服アクション**: 新卒採用シグナル（ナビ掲載等）でリードを事前スクリーニングし、この層への架電を削減（既存の新卒フラグ enrich を活用）。

### シーン⑧ 「LINEは方針・セキュリティでNG」（73件・1.2%）
- 実際の断り: 「LINEは会社的にNG」「セキュリティ面が気になる」
- **克服すべき核心**: 件数は少ないが、**セキュリティ懸念はアポ後も残る論点**（アポ獲得側にも「LINEのセキュリティ面が気になっている」で商談化した例＝懸念があっても話は聞く）。
- **克服トーク**: 懸念を否定せず「その懸念をお持ちの企業がどう導入したか」の**導入事例＋セキュリティ仕様**を先出し。NGを恐れて訴求を弱めない。

> **優先度の結論**: 克服“トーク”で効くのは①現状肯定（診断質問）と②公式LINE誤解（差分提示＋歩留への切替）で、ここが接続後お断りの約2割強を占める最大の攻めどころ。③ネオキャリア・バッティングと⑦ICP外は“トークでなく運用（名寄せ・リスト精度）”で潰すべき損失。
